# PathfindingWithBreadth-First-Search

This C++ program creates a randomly generated 10×10 grid with walls, a random starting point, and a random goal point located along the exterior of the grid. It uses Breadth-First Search (BFS) to explore the grid, track visited nodes, and find the shortest available path from the start to the goal. The program then reconstructs and displays the path along with the generated grid.
